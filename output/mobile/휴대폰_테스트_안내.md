# 휴대폰 테스트

공개 게임 주소: https://leegeonmyeong.github.io/MonsterStrikeRunner/
저장소: https://github.com/LeeGeonMyeong/MonsterStrikeRunner

1. 휴대폰 Chrome 또는 Safari에서 공개 주소를 엽니다. 게임 설치나 PC와 같은 Wi-Fi 연결은 필요하지 않습니다.
2. 로딩 완료 후 START를 누릅니다.
3. 화면을 좌우로 스와이프해서 차선을 바꿉니다.
4. ATTACK을 눌러 일반 공격을 확인합니다.
5. HOLD CHARGE를 0.65초 이상 누른 뒤 놓아 관통 공격을 확인합니다.
6. 일반 처치 50점, 강화 처치 90점, 이동·생존만으로 점수가 증가하지 않는지 확인합니다.
7. 몬스터를 놓치면 HP가 줄고, HP 0 결과 화면에서 RESTART로 새 판을 시작하는지 확인합니다.
8. 화면 회전, 스크롤 방지, 버튼 위치와 글자 크기를 확인합니다.

이전 게임이 보이면 새 탭 또는 시크릿 탭으로 열어 캐시 영향을 줄이세요.

## 용량

현재 전투 버전의 기존 로컬 웹 파일: 69,579,551 bytes (66.36 MiB)
최적화한 웹 파일: 10,647,469 bytes (10.15 MiB)
약 84.7% 감소. 이는 파일 크기 합계이며 브라우저 통신 헤더·캐시·다른 소스 파일을 포함하지 않습니다.

## 최적화

- 캐릭터 WebGL 텍스처 최대 256px, 배경 최대 1024px. 원본 PNG는 유지합니다.
- 로딩 캐릭터 이미지를 160px 높이로 축소했습니다.
- Disk Size with LTO, High 관리 코드 제거, OptimizeSize 코드 생성 적용.
- Brotli 압축과 내장 압축 해제로 GitHub Pages의 별도 헤더 설정 없이 로딩하도록 구성.
- 휴대폰 렌더링 배율을 1로 제한해 GPU 부담을 줄였습니다.

Brotli와 크기 최적화는 Unity 공식 모바일 Web 최적화 지침을 참고했습니다:
https://docs.unity3d.com/6000.3/Documentation/Manual/web-optimization-mobile.html
GitHub Pages 호환 압축 해제 설정:
https://docs.unity3d.com/6000.3/Documentation/Manual/webgl-deploying.html
