# 한글화와 짧은 조작 연습

## 반영 범위

- 시작, 체력·시간·점수·처치·단계, 일반·충전 공격, 경고, 결과·재시작, 웹 로딩과 오류 안내 한글화.
- 한글 글꼴 내장: Runner Korean (Noto Sans KR 파생), 약 39KB. 원본 글꼴 라이선스와 출처 포함.
- 첫 플레이 3단계: 스와이프 이동 → 일반 공격 → 끝까지 충전한 뒤 발사.
- 연습에는 몬스터가 없고 시간·체력·점수가 변하지 않음.
- 충전이 짧으면 다음 단계로 넘어가지 않고 다시 안내.
- 연습 완료 후 점수·피해 규칙을 설명하고 본 게임으로 진입.
- 건너뛰기와 시작 화면에서 재연습 지원. 완료 여부는 같은 브라우저에 저장.
- 일반 50점·강화 90점, 놓치면 체력 1 감소, 60초 제한 유지. 추가로 묶은 공격·난이도·아트 수정은 [통합 수정 안내](피드백_통합수정.md)를 참고하세요.

## 확인

Unity의 조작 연습 자동 검사와 기존 전투 회귀 검사 통과. 첫 실행·잘못된 입력·충전 재시도·글자 누락·연습 안전성·완료 후 초기화·재시작·건너뛰기를 확인했습니다.

검사 로그: DevelopmentBackup/KoreanTutorialCheck.log, KoreanCombatRegression.log.
원본 백업: DevelopmentBackup/BeforeKoreanTutorial.

브라우저에서는 [게임 시작]을 눌러 연습하고, 이후 [조작 연습 다시 하기]로 재확인할 수 있습니다. 실제 스마트폰의 터치감은 추가 확인이 필요합니다.
