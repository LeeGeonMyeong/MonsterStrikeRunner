# v1.1.0 게임 피드백 반영

## 구현
- 궁수는 위쪽, 몬스터는 아래쪽으로 향하는 수직 탑뷰 이미지로 교체했습니다. 기본 화풍과 색감은 유지합니다.
- 6초부터 8초마다 회복 아이템과 보너스 수정이 번갈아 무작위 차선에 등장합니다. 몸으로 획득하며 아이템을 놓쳐도 피해는 없습니다.
- 초록 십자: 체력 +1, 최대 체력에서는 +50점. 금색 수정: +100점.
- 아이템 점수는 몬스터 처치 수와 별도 집계합니다. 결과에 획득 수와 보너스 합계를 표시하고 재시작 시 초기화합니다.
- 시작·튜토리얼·전투·결과 화면 오른쪽 위에 v1.1.0을 표시합니다.
- 화면 회전과 크기에 맞춰 게임 화면을 조정하고 노치·홈 표시 영역의 안전 여백을 계산합니다.

## 모바일 지원 근거
Unity 6.3의 공식 지원 대상에는 iOS Safari 15 이상과 Android Chrome 58 이상이 포함되며, 최신 브라우저를 권장합니다. 특정 휴대폰 모델 전용으로 제작하지 않았지만 모든 실기종의 직접 검증을 완료한 것은 아닙니다.
https://docs.unity3d.com/6000.3/Documentation/Manual/webgl-browsercompatibility.html
