# Monster Strike Runner v1.1.1

몬스터를 공격해 처치하고 방어선을 지키는 모바일 세로형 2D 러너입니다. 시작 → 전투 → 결과 → 재시작으로 한 판을 반복합니다.

## 전투 규칙

- 60초 생존, HP 3으로 시작합니다.
- 일반 몬스터(보라색)는 HP 1, 강화 몬스터(주황색)는 HP 2입니다. 머리 위 표시로 남은 체력을 확인합니다.
- 현재 플레이어의 가로 위치에서 앞으로 발사합니다. 왼쪽의 ◀ / ▶ 버튼으로 몬스터의 차선에 맞춰 공격하세요.
- 일반 공격은 피해 1이고 첫 몬스터에 맞으면 사라집니다. 재사용 대기 시간은 0.35초입니다.
- 공격 버튼을 0.45초 이상 누른 뒤 놓으면 피해 2의 관통 공격을 발사합니다. 완충 공격의 회복 시간은 0.12초로, 같은 줄의 여러 적과 강화 몬스터에 유리합니다. 짧게 누르고 놓으면 일반 공격과 같은 피해 1입니다.
- 시작 2초는 준비 시간이며, 처음 15초에는 일반 몬스터만 등장합니다. 출현 간격은 2.3초에서 1.05초로, 이동 속도는 15초마다 2.6 → 약 4.07 → 약 5.53 → 7.0으로 뚜렷하게 높아집니다. 단계 사이에는 속도가 일정하며, 단계 변경 시 첫 단계 대비 속도 배율을 표시합니다.
- 몬스터가 화면 아래로 완전히 벗어나면 어느 차선이든 한 마리당 HP 1과 점수 최대 30이 감소합니다. 플레이어와 겹치거나 바로 뒤를 지나는 것만으로는 피해를 받지 않습니다.
- 일반 몬스터 처치 +50점, 강화 몬스터 처치 +90점. 아이템도 보너스 점수를 줍니다. 시간 경과나 이동만으로 점수가 오르지 않습니다. 점수는 음수가 되지 않습니다.
- HP 0 또는 60초 경과 시 결과 화면에 최종 점수, 처치 수, 놓친 수, 아이템 획득 수와 보너스 합계를 표시합니다.
- 재시작하면 HP, 점수, 처치·누락 수, 몬스터, 충전 상태를 초기화합니다.

## 아이템

초록 십자가 회복 아이템만 등장합니다. 몸으로 획득하면 체력 1을 회복하고, 체력이 가득 찼을 때는 50점으로 전환합니다. 놓쳐도 피해는 없습니다. 첫 아이템은 6초, 이후 8초 간격으로 나옵니다.

## 플레이 조작 3종

| 입력 방식 | 모바일 조작 | 역할 |
| --- | --- | --- |
| 이동 버튼 | 왼쪽 ◀ / ▶ 클릭 | 차선 변경과 공격 방향 조준 |
| 클릭 버튼 | 오른쪽 [공격]을 짧게 누르고 놓기 | 일반 공격 |
| 홀드 버튼 | 같은 [공격]을 길게 누른 뒤 놓기 | 시간에 따라 위력이 달라지는 충전 공격 |

세 방식이 한 플레이 화면에서 함께 사용됩니다. 시작·재시작 버튼은 조작법 3종에 포함하지 않습니다. PC에서는 좌우 방향키, Space(일반 공격), 아래 방향키 유지 후 해제(충전 공격)를 사용합니다.

## 한글 UI와 첫 플레이 조작 연습

시작·전투·결과·로딩 화면을 한글로 표시합니다. 휴대폰에서도 글자가 누락되지 않도록 필요한 글자만 포함한 한글 글꼴을 게임에 내장했습니다.

처음 [게임 시작]을 누르면 아래 세 동작을 직접 해 보는 조작 연습이 시작됩니다.

1. 왼쪽 ◀ / ▶ 버튼을 눌러 한 차선씩 이동합니다. PC 좌우 방향키도 사용할 수 있습니다.
2. [공격]을 짧게 눌렀다 떼어 앞으로 발사합니다.
3. 같은 [공격]을 길게 누른 뒤 막대가 가득 차면 손을 뗍니다.

연습 중에는 몬스터가 나오지 않고 시간·체력·점수가 변하지 않습니다. 짧은 충전은 재시도 안내를 표시합니다. 완료 화면에서 피해와 점수 규칙을 확인하고 [전투 시작]을 누릅니다. 연습 동작과 발사체는 본 게임으로 이어지지 않습니다.

완료하거나 [연습 건너뛰기]를 누르면 같은 브라우저·프로필의 다음 플레이부터 바로 시작합니다. 시작 화면의 [조작 연습 다시 하기]로 언제든 다시 볼 수 있습니다. 새 브라우저나 저장 데이터 삭제 후에는 다시 표시됩니다.

글꼴: Google Fonts Noto Sans KR에서 만든 Runner Korean UI 서브셋(SIL OFL 1.1). 라이선스는 Assets/Resources/Fonts/OFL.txt에 있습니다. 한글 문구를 추가할 때 tools/subset_korean_font.py로 글꼴을 다시 생성해야 합니다.

## 실행과 웹 빌드

숲 배경과 맞춘 청록 궁수·보라 수정 몬스터를 수직으로 내려다보는 탑뷰 스프라이트로 사용합니다. 달리기 리듬, 차선 이동 기울기, 공격 반동, 충전 떨림, 피격 반응, 처치 시 회전·축소·사라짐을 적용했습니다. 이미지 생성 기록과 변경 범위는 [통합 수정 안내](output/tutorial/피드백_통합수정.md)에 있습니다.

- Unity 6000.3.23f1 / Input System / WebGL. 캔버스와 UI 기준 480 × 854. 화면 오른쪽 위에 v1.1.1을 표시합니다.
- Assets/Scenes/SampleScene을 열고 Play → 게임 시작으로 실행합니다. Inspector 연결 작업은 추가로 필요하지 않습니다.
- Runner → Build Web for GitHub Pages 메뉴는 프로젝트 루트 docs에 웹 빌드를 생성합니다.
- 커스텀 RunnerPortrait 템플릿, Brotli 압축, Decompression Fallback 활성화, 코드 용량 최적화(LTO), WebGL 관리 코드 High stripping, SampleScene 포함으로 빌드합니다.
- Build And Run 또는 HTTP 서버로 실행해야 합니다. index.html을 더블클릭하는 file:// 실행은 지원하지 않습니다.

## 휴대폰 지원 범위

특정 모델 전용이 아닌 웹 게임입니다. 화면 크기와 회전에 맞춰 세로 게임 화면을 맞추고 iOS 노치·홈 표시 영역의 안전 여백을 고려합니다. Unity 6.3 공식 브라우저 지원 기준은 iOS Safari 15 이상과 Android Chrome 58 이상이며 최신 브라우저 사용을 권장합니다. 모든 실기종을 직접 검사했다는 뜻은 아닙니다.
